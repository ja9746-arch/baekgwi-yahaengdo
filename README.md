# 백귀야행도 — 대문

백귀관상 · 백귀사주 · 백귀타로 세 서비스를 묶는 첫 화면.

## 구성
| 파일 | 하는 일 |
|---|---|
| `index.html` | 대문 전체 |
| `reviews.js` | 실제 받은 후기를 넣는 곳 (비어 있으면 후기 칸이 안 나옴) |
| `sayings.js` | '오늘의 말' — 술사 세 명이 번갈아 하는 한마디 |
| `snippet-review-button.html` | 사주·타로 풀이 끝 화면에 붙일 '후기 남기기' 버튼 |

## 손볼 곳
`index.html` 아래쪽 `const LINKS` 한 군데.
주소를 비워 두면 그 버튼은 "준비 중입니다" 안내가 뜹니다.

## 후기 운영
1. 후기 받을 곳을 하나 만듭니다 (구글 폼이 가장 빠름).
2. 그 주소를 `LINKS.reviewForm` 과 `snippet-review-button.html` 에 넣습니다.
3. 후기가 들어오면 `reviews.js` 에 한 줄씩 추가합니다.
4. 한 줄이라도 들어가면 대문에 후기 칸이 저절로 생기고, 세 개씩 돌아갑니다.

지어낸 후기는 넣지 마세요. 표시광고법에서 막는 후기 조작에 해당합니다.

## 배포
정적 파일이라 그대로 올리면 됩니다. (Vercel: 프레임워크 없음 / 빌드 명령 없음)

## 나중에 한 주소로 묶을 때
이 저장소에 도메인을 붙이고 `vercel.json`에 리라이트를 넣어
`/gwansang`, `/saju`, `/tarot`을 각 프로젝트로 넘기면 됩니다.
